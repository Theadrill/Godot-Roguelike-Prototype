# Godot Roguelike Prototype

Este repositório é um **protótipo de testes pessoais** para desenvolvimento assistido por IA, tendo como referência de combate e movimentação jogos do gênero Roguevania / Action Roguelike 2D (inspirado em Dead Cells).

## Objetivo
- Prototipar e validar a jogabilidade e o *game feel* (movimentação ágil, pulo, rolamento, esquiva, combate corpo a corpo e hitstop).
- Testar a arquitetura e fluxos de desenvolvimento da Godot 4 com auxílio autônomo de agentes de IA.
- Este projeto foca inicialmente em mecânica e física; assets artísticos complexos não são o foco nesta fase inicial de testes.

## Status do Projeto
- Fase: **Planejamento e Preparação de Ambiente** (Nenhum código de gameplay gerado ainda).
