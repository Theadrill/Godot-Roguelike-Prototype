# Regras do Projeto - Fluxo de Versionamento Git

1. **Apenas Commits Locais**:
   - Todas as alterações, mecânicas e documentos devem ser commitados apenas no repositório local (`git commit`).
2. **Proibido Push Automático**:
   - NUNCA executar `git push` ou enviar alterações para repositórios remotos sem pedido explícito do usuário.
3. **Comportamento sob Demanda de Push**:
   - Quando o usuário pedir especificamente um push, realizar exatamente aquele único push solicitado e aguardar novas instruções.
